# Strata evaluation plan: RX 9070 XT, 16 GiB

Keep the [UD-IQ3_XXS recipe](../../recipes/qwen3.8-flash-next-gguf-unsloth-ud-iq3-xxs-rx-9070-xt-16-gb-vram/recipe.md) as the serving default. Start with the [packaged v0.2.17 trial](../runtimes/strata.md#try-strata-v0217). Then compare the source build with the pinned container, evaluate routing fidelity, and tune KV residency if the measurements justify it.

## Reference and controls

The [runtime lock](../../runtimes/strata/container/versions.lock.json) pins Strata `dbb2d168` (engine 0.1.59.1), [95 commits after v0.2.13](https://github.com/Niko1221/Strata/compare/v0.2.13...dbb2d168cffa8cf793d9325358809d5263c7c6b0). The reference uses HIP MMQ prefill, automatic expert caching, INT8 KV, 131,072 context tokens, 32,768 resident cells, Q2_0 MTP (`--spec 4 --spec-min-p 0.5`), and CPU vision.

- [Baseline 002](../../recipes/qwen3.8-flash-next-gguf-unsloth-ud-iq3-xxs-rx-9070-xt-16-gb-vram/002-2026-11-15-baseline/summary.md): suite v2, at 119,492 input tokens, first output took 37.10 s and decode reached 85.83 tok/s; peak VRAM was 15.3/15.9 GiB. At 8K, the five-run decode range was 10.6% of the median. Treat those numbers as context, not pass/fail thresholds.
- [Coding session 003](../../recipes/qwen3.8-flash-next-gguf-unsloth-ud-iq3-xxs-rx-9070-xt-16-gb-vram/003-2026-11-15-coding/summary.md): 1,846 of 1,947 requests were at least 32K tokens and about 97% of prompt tokens were reused. Returning long conversations matter more here than a short, cold prefill record.

Use the [candidate-runtime workflow](../runtimes/strata.md#compare-a-candidate-runtime) and the [baseline suite](../baseline.md). Keep the model and drafter revisions, client, sampling settings, and request fixtures fixed. Record the ROCm digest for each arm. Hold it fixed for any trial that isolates an engine or setting change. Alternate reference and candidate runs from fresh starts; warm each identically and build reuse within each run, not across runs. Record image ID, source revision, build flags, effective engine arguments and routing environment with each result. Separate cold prefill, warm time to first visible output, and decode. Report medians and ranges. Use suite v3’s automatic long replay for warm latency and cache reuse. Compare results at the same replay tier. Use the scripted coding turns below to check tool-call fidelity with the same prompt sequence, reasoning effort, and output cap in both runs.

## 1. Engine 0.1.63 and native CPU vision

[Strata v0.2.17](https://github.com/Niko1221/Strata/releases/tag/v0.2.17) ships engine **0.1.63**, including a Linux HIP package for the RX 9070 series. The [source commit](https://github.com/Niko1221/Strata/commit/12d491da4a6904eb49aaa6f2f63ec4b1a17582e3) also declares 0.1.63. The packaged trial checks the upstream distribution. Evaluate the source-built ROCm 10.2 container under a separate candidate image tag for Unsloth UD-IQ3_XXS.

- **Routing.** Leave `STRATA_ROUTE_TAIL_SKIP` unset in the v0.2.17 serving recipe. Both the engine and upstream launcher default to off. Upstream’s R9700 produced different tokens on all ten BASE-05 prompts with the new default and reproduced the earlier tokens with rank 7. This measures output identity. The reported 1.29× decode gain at rank 7 was on an RTX 5090 with UD-Q4_K_XL and DFlash2. [Release measurements](https://github.com/Niko1221/Strata/releases/tag/v0.2.17)
- **RDNA4 defaults.** Leave WMMA prompt attention on automatic on Linux, the PCIe miss split at its gfx12 starting fraction of 0.15, and PLE table placement on automatic. Upstream measured 32K decode at 67.2 → 84.4 tok/s when moving the split from 0.55 to 0.15 on an R9700 with IQ3_S. Forcing PLE into RAM can consume another 26.8 GiB. Leave `STRATA_HIP_PROMPT_F16` unset on gfx1201; upstream measured slower dense GEMMs on the R9700. [Upstream RDNA4 results](https://github.com/Niko1221/Strata/blob/v0.2.17/docs/AMD_HIP.md#rdna4-gfx1201)
- **Host memory.** Setup’s 47 GiB expert budget on a 64 GiB PC applies to UD-Q4_K_XL and UD-IQ4_XS. Keep automatic expert caching for Unsloth UD-IQ3_XXS. The Linux HIP NUMA fix and container memory-accounting fixes warrant repeated starts. Record time to readiness, expert slots, RAM, VRAM and swap growth through the first request. Upstream saw 0–16 MiB swap growth on the R9700 with this release. [RAM policy](https://github.com/Niko1221/Strata/blob/v0.2.17/terminal/setup.py)
- **Pi.** Exercise streamed calls with multiline file contents containing literal `</parameter>`, a tool result followed by another call, and a final answer after reasoning. The release fixes parsing in each of these areas. Run this at the usual Pi medium effort alongside the standard baseline’s thinking-off checks.
- **Drafting and hardware.** Keep the recipe’s Q2_0 MTP. The tagged drafting policy still lists an open DFlash2 prompt stall on gfx1201. Upstream’s adaptive fetch and short-prompt throughput figures apply to NVIDIA Blackwell. The Coder checkpoint update concerns a separate model. [Draft policy](https://github.com/Niko1221/Strata/blob/v0.2.17/terminal/strata_control/drafting.py)

## 2. Routing fidelity

If returning-turn decode warrants a speed trial, compare the unmodified candidate with a copy that sets `"env": {"STRATA_ROUTE_TAIL_SKIP": "7"}` in the native config. Rank 7 skips copying and computing an expert when it misses the GPU cache and every token in the verification window ranks it seventh or lower. Check the engine log for a rising `route tail skip: ... missed experts skipped` count during the workload. If it stays inactive, omit the timing comparison. [Upstream routing controls](https://github.com/Niko1221/Strata/blob/v0.2.17/terminal/strata_control/speed_switches.py)

Replay sanitized coding turns with a known expected tool name and arguments. Include multiline patches, escaped strings, nested arguments, and an instruction near the start of a long conversation. Compare parsed argument values, byte-exact file payloads where required, task success, decode speed, and draft acceptance. [Issue #5225](https://github.com/Niko1221/Strata/issues/5225) motivates the test, not a claim that disabling skipping cures malformed calls. Keep skipping off unless rank 7 gives a repeatable latency benefit while preserving task success and tool arguments.

## 3. GPU KV residency at fixed context

Compare `--kv-resident` **32768 → 65536 → 131072**, keeping `--max-context 131072`, `--kv int8`, and `--expert-cache auto` fixed. The reference already serves 120K prompts: the question is latency, not context capacity. At 131,072 resident cells the requested main KV residency covers the configured context. Check actual allocation in the startup log because it shares VRAM with the expert cache.

Prerequisite: [`configure()`](../../runtimes/strata/scripts/serve.py) rewrites residency to `min(context, 32768)`, so editing native JSON alone cannot run this test. In the experiment worktree, first test that the reference still resolves to 32,768 and a recipe-specified cap resolves to the lesser of that cap and the requested context; then implement the override. Verify the effective values in the engine startup log for each arm.

Measure KV block hits and RAM reads **alongside** allocated expert slots, expert hits, warm latency, decode, VRAM, RAM and swap. Include retrieval of an early instruction at 120K, not just successful generation. Stop increasing residency on allocation failure or memory pressure that harms serving. Keep 32,768 unless a larger pool improves the long coding turns beyond run variability.

## Community results and transferable checks

A [community RX 9070 XT run](https://github.com/Niko1221/Strata/pull/6224) used Ubuntu, 64 GB DDR4, ISTA IQ3_XXS and engine 0.1.58. It reported 59.7 tok/s median decode and 2,697 tok/s prefill at 16K. Use it as a same-card reference for that older engine. The v0.2.17 release review uses an R9700 for the AMD output comparison.

A [LocalLLM report](https://www.reddit.com/r/LocalLLM/comments/1xxpvtu/) claims 5,600 tok/s prefill at 100K and 100 tok/s decode with a 181K context setting on two RX 7900 XTX cards, 64 GB DDR5, and Q4_K_M weights, using layer split without tensor parallelism. Those details come from the public post title. The configuration and measurement method are unverified. The two cards provide 48 GB of aggregate VRAM across two RDNA3 devices, so use the local single-card IQ3_XXS measurements as the reference. Keep the engine and KV trials at 131,072 context and compare cold prefill separately from returning-turn latency.

If the residency sweep shows that KV memory is the constraint, first A/B the pinned engine’s existing `--kv k8v4` against `--kv int8` at the same context and resident-cell count. The [pinned source](https://github.com/Niko1221/Strata/blob/dbb2d168cffa8cf793d9325358809d5263c7c6b0/src/program/generate.cpp#L1041-L1054) describes INT8 keys plus rotated Q4_0 values at 816 bytes per cell versus 1,056 for INT8. Those figures describe the KV format. Measure total VRAM, RAM, and expert-cache slots because automatic sizing may spend the savings on experts. Repeat 120K retrieval and warm tool-call checks before trying more resident cells with the smaller format.

When the posted configuration is available, shortlist only settings present on the selected HIP revision with a single GPU and IQ3_XXS. Test each against the same build and prompt sequence. Treat split placement, RDNA3-specific kernel overrides, and Q4_K_M-specific paths as properties of the reported setup.

## Community patches: conditional trials only

- [#6085, `STRATA_IQ_FAST`](https://github.com/Niko1221/Strata/pull/6085): first patch to trial **if CPU expert work is a bottleneck**. The Ryzen 7 9800X3D supports the required AVX-512 VBMI. Compare off/on in the same patched image; judge end-to-end decode, not just IQ3_XXS CPU row throughput.
- [#6176, `q4u32` KV](https://github.com/Niko1221/Strata/pull/6176): defer unless KV memory limits the winning configuration. The cited 32K result is from a Windows RX 9060 XT. Explicit `--kv int8` does not exercise the new format; test the format separately and repeat 120K retrieval and tool fidelity checks.
- [#6161, RX 9070 XT at 131K](https://github.com/Niko1221/Strata/pull/6161): benchmark evidence, not a code patch. Its Windows Gyro-S run changed eight settings together and kept 32,768 resident cells. Do not import the bundle as a Linux IQ3_XXS preset.

Publish each measured configuration as a separate recipe experiment. If no candidate earns promotion, keep the baseline runtime and recipe unchanged.
